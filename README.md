# PyLoader

Локальное приложение для скачивания видео, музыки, плейлистов и каналов через `yt-dlp` и FFmpeg —
с медиатекой, встроенным плеером, плейлистами и передачей файлов на телефон по Wi-Fi.

## Быстрый старт (Windows)

1. Установите [Python 3.10+](https://www.python.org/downloads/).
2. Дважды щёлкните **`PyLoader.bat`**. При первом запуске он создаст `.venv`, установит зависимости
   и положит ярлык **PyLoader** на рабочий стол и в меню «Пуск».
3. Дальше запускайте PyLoader ярлыком: сервер стартует без чёрного окна, а приложение открывается
   отдельным окном (Edge/Chrome в режиме приложения). Повторный запуск просто открывает окно.
   Выключить сервер — «Настройки → Выключить PyLoader».

Ярлык можно пересоздать вручную:

```powershell
.\.venv\Scripts\python.exe scripts\create_shortcut.py
```

### Запуск из консоли

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Откройте [http://127.0.0.1:5000](http://127.0.0.1:5000). Интерфейс намеренно слушает только локальный адрес.
После обновления проекта повторите `pip install -r requirements.txt` (`PyLoader.bat` делает это сам).

FFmpeg можно оставить рядом с `main.py` (`ffmpeg.exe`, `ffprobe.exe`) либо добавить в `PATH`. Node.js используется
`yt-dlp` для современных YouTube-плееров.

## Возможности

**Загрузка**
- вставка ссылок откуда угодно: `Ctrl+V` в любом месте окна, перетаскивание в окно, кнопка «В PyLoader» для панели
  закладок; ссылки извлекаются из любого текста;
- пакетный анализ ссылок, плейлистов и каналов; отметка того, что уже есть в медиатеке, кнопка «Только новые»;
- дедупликация по YouTube ID внутри пакета, активной очереди и медиатеки;
- MP3 (128–320 кбит/с), M4A, OPUS, MP4 и MKV; видео до 8K; субтитры и автосубтитры;
- папки и нумерация для плейлистов; cookies браузера; прокси;
- очередь с вкладками, общим прогрессом, честным прогрессом для видео+аудио, отменой и повтором всех ошибок;
- прогресс в заголовке вкладки и системное уведомление, когда очередь закончилась.

**Медиатека и плеер**
- список и плитка, поиск по названию/исполнителю/плейлисту, фильтры, избранное, сортировки;
- множественный выбор (`Shift`, `Ctrl`, `Ctrl+A`), контекстное меню, массовые действия;
- плеер внизу окна: очередь, «играть следующим», перемешивание, повтор, громкость, видео поверх окна,
  медиаклавиши клавиатуры и экран блокировки (Media Session); очередь и позиция помнятся после перезапуска;
- свои плейлисты (перетаскивание треков в плейлист в боковой панели и сортировка перетаскиванием)
  и автоматические коллекции из скачанных плейлистов YouTube;
- индекс медиатеки в `downloads/.pyloader/` (`library.json`, `playlists.json`, `bridge.json`).

**На телефон**
- включите «На телефон → Доступ с телефона» и отсканируйте QR-код: на телефоне откроется медиатека
  с плеером, плейлистами и вкладкой «Отправленное»;
- кнопка «На телефон» у любого трека или выделения кладёт файлы в «Отправленное»; на компьютере видно,
  что телефон их уже сохранил;
- доступ только в локальной сети и только по ключу из QR-кода; «Сменить ключ» отключает все телефоны.
  API для будущего мобильного приложения описан в [docs/mobile-bridge.md](docs/mobile-bridge.md).

**Оформление**: тёмная, светлая и системная темы, горячие клавиши (см. «Настройки»).

## Настройка

- `PYLOADER_WORKERS` — параллельные загрузки, по умолчанию `3`, максимум `8`.
- `PYLOADER_PORT` — локальный порт, по умолчанию `5000`.
- `PYLOADER_BRIDGE_PORT` — порт доступа с телефона, по умолчанию `5001`.
- `PYLOADER_BROWSER=default` — ярлык открывает обычный браузер вместо окна-приложения.
- `PYLOADER_DEBUG=1` — режим Flask debug без автоматического reloader.

Высокая параллельность может вызвать временные ограничения YouTube, поэтому штатное значение — три задачи.
