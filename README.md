# PyLoader

Локальное веб-приложение для удобного скачивания видео, аудио, плейлистов и каналов через `yt-dlp` и FFmpeg.

## Возможности

- пакетный анализ нескольких ссылок, плейлистов и каналов;
- дедупликация по YouTube ID внутри пакета, активной очереди и локальной медиатеки;
- MP3 (128–320 кбит/с), M4A, OPUS, MP4 и MKV;
- качество видео до 8K, если оно есть у источника;
- субтитры и автоматические субтитры для видео;
- сохранение порядка и отдельные папки для плейлистов;
- cookies из Chrome, Edge, Firefox или Brave для доступного вам защищённого контента;
- прокси, повтор ошибок, отмена задач, скорость и ETA;
- постоянный локальный индекс медиатеки в `downloads/.pyloader/library.json`;
- безопасное удаление и открытие файлов в Проводнике.

## Запуск

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Откройте [http://127.0.0.1:5000](http://127.0.0.1:5000). Приложение намеренно слушает только локальный интерфейс.

FFmpeg можно оставить рядом с `main.py` (`ffmpeg.exe`, `ffprobe.exe`) либо добавить в `PATH`. Node.js используется `yt-dlp` для современных YouTube-плееров.

## Настройка

- `PYLOADER_WORKERS` — параллельные загрузки, по умолчанию `3`, максимум `8`.
- `PYLOADER_PORT` — локальный порт, по умолчанию `5000`.
- `PYLOADER_DEBUG=1` — режим Flask debug без автоматического reloader.

Высокая параллельность может вызвать временные ограничения YouTube, поэтому штатное значение — три задачи.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts\audit_library.py <playlist-url> [<playlist-url> ...]
```
